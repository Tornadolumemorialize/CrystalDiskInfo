## 🚀 What is CrystalDiskInfo?

**CrystalDiskInfo** is crystalDiskInfo is a Windows storage-monitoring utility for drive health, S.M.A.R.T. attributes, temperature, interface information, and supported device controls.

## ✨ Key Features

| 🎯 Health Status | ⚡ Temperature | 🧩 Drive Details |
| :---: | :---: | :---: |
| **Health Status**<br>View drive health information and S.M.A.R.T. attributes. | **Temperature**<br>Monitor current storage temperatures. | **Drive Details**<br>Inspect firmware, serial information, interface, transfer mode, and drive letters. |

| 🔧 NVMe & SATA | 🚀 Graphs & Alerts | 💎 AAM / APM |
| :---: | :---: | :---: |
| **NVMe & SATA**<br>Monitor supported modern storage interfaces. | **Graphs & Alerts**<br>Review supported history and configure notifications. | **AAM / APM**<br>Access supported acoustic and power-management settings. |
